# 诊断工具

这些页面是**二分定位**用的，不是应用的一部分。留着是为了下次再出现
"只在某个方向 / 某台设备上崩"的问题时，可以从结论开始。

打开方式：`http://<地址>:24051/diag/`（竖屏或横屏都行，见下面的注意事项）

## 目录

| 页面 | 用途 |
|---|---|
| `index.html` + `N*/M*/K*` | 横屏崩溃的二分变体，见下文。**不能用 iframe 或注入来测** |
| `preview.html` | 四个界面并排放在 812×375 的 iframe 里，看横屏排版 |
| `anim-probe.html` | 驱动真实的切屏，采样浏览器算出来的 opacity / transform |
| `backdrop-probe.html` | 四屏各自套上对应的背景滤镜，用真实谱面图看效果 |

后三个是**看排版、动画和背景**用的，和二分变体不是一回事：它们把真实页面放进 iframe，
这在"首屏布局"类问题上无效（下面会解释），但对排版和动画完全成立。

`backdrop-probe.html` 只改 iframe 里的 `body[data-page]` —— 那正是样式表用来决定每屏
背景滤镜的属性。程序本身只在换屏时重写它，所以状态稳定时这个覆盖会一直有效。
背景图来自 `/api/background`，也就是**游戏里当前选中的那张图**，所以调背景时要先在
osu! 里选好一张有图的谱面。

**它需要源码版**：打包后的 exe 从自己的 bundle 里读前端文件，改仓库里的 CSS 或加新页面
它都看不到。调背景时开源码版（`python -m osu_live --port 24053`），静态文件是每次请求
现读的。

## 已解决的问题：横屏首屏崩溃（iOS Safari）

### 症状

- **竖屏**：一切正常
- **横屏直接打开**：整个页面被丢弃，提示"重复出现问题"
- **先竖屏打开、再转到横屏**：完全正常

第三条是突破口——说明**布局本身是合法的**，是"首屏就在横屏"这个时序出问题。

### 结论

> **`.page` 这个 fixed 全屏容器上的 `display: grid` 会让 iOS Safari 在首次布局时崩溃。**

改成 flex 即可。**内容布局里的 grid 完全无关**，一行都不用改。

```css
.page.active { display: flex; flex-direction: column; }
.page > .body { flex: 1 1 auto; padding-top: var(--head-band); }
```

原来标题带的高度是用 grid 行预留的，现在改成 `padding-top`——**用 grid 行预留空间正是要避开的东西**。

### 证据链

| 变体 | 改动 | 结果 |
|---|---|---|
| **K1** | 只有外层 `.page` 用 flex，内容 grid 保留 | ✅ **正常** |
| **K2** | 只有内容 `.body` 用 flex，外层 grid 保留 | ❌ 崩 |
| **K3** | grid 全保留，只把 `fixed` 换成 `absolute` | ❌ 崩 |

K1 正常而 K2/K3 崩溃 ⇒ 问题在外层容器的 `display` 值，不在内容布局，也不在定位方式。

### 被排除的方向（全部有实验证据）

| 猜测 | 实验 | 结果 |
|---|---|---|
| 媒体查询的求值 | 规则无条件生效，去掉查询包裹 | 照样崩 |
| `var()` 用在 grid 轨道 | 换成固定像素 | 照样崩 |
| `minmax(0, 1fr)` | 去掉 | 照样崩 |
| `align-content` | 不动它 | 照样崩 |
| 标题带用 grid 行预留 | 改用 padding | 照样崩 |
| `filter` / `backdrop-filter` | 关掉 | 照样崩 |
| 渐变（含 `conic-gradient`） | 关掉 | 照样崩 |
| 背景层的 `transform` | 关掉 | 照样崩 |
| `100dvh` | 换成 `100%` | 照样崩 |

**前四条是当初实际动手改过的方向，全都错了。** 记录在此，避免重走。

### 三轮二分的变体

- **N 轮**（第一轮）：`N0` 对照，`N1` 删掉横屏媒体查询，`N2` 禁 filter，`N3` 禁渐变，`N4` 禁合成，`N5` 禁 dvh，`N6` 退回 flex
- **M 轮**（第二轮）：`M1` 规则无条件生效，`M2` 轨道去 `var()`，`M3` 去 `minmax`，`M4` 不动 `align-content`，`M5` 标题带改 padding，`M6` 退回 flex
- **K 轮**（第三轮）：`K1`/`K2`/`K3` 见上表

## 踩过的坑：别用"注入覆盖"做这类诊断

第一版变体是把真实页面放进 iframe，再用 JS 往里面注入覆盖样式。
**这整个方法是无效的**——iframe 一加载就完成首次布局，包装页的脚本
根本来不及跑，覆盖从未生效。

当时那些变体"崩溃"的结果被我当成了证据，实际证明不了任何事。

**正确做法**：变体必须是**自己的页面**，样式表第一行 `@import` 真实
样式表，后续规则直接覆盖。`@import` 在解析期生效，所以首次布局之前
规则就已经到位。

另外：`@import` 相对**样式表自己**的位置解析，不是相对 HTML。
从 `diag/` 引用要写 `../style.css`。
