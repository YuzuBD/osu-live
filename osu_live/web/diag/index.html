osu! live — 诊断

从 1 开始逐个点。哪个崩，就是那个原因。每个都不用等太久。

  1. v1 纯静态只有 HTML 和内联样式，不加载 app.js / style.css。这一项若崩，和页面无关。
  2. v2 只加载 CSS真实样式表，脚本被剥掉。崩 → 样式；不崩 → 脚本。
  3. v3 禁用渐变与模糊针对 conic-gradient / linear-gradient / filter。会自动换图 15 次。
  4. v4 禁用 dvh 与 fixed针对动态视口单位和固定定位。会自动换图 15 次。
  5. v5 禁用一切动画针对过渡与补间。会自动换图 15 次。
  6. v6 完整页面（对照）预期会崩，用来确认环境没问题。
每一步只需要告诉我两件事：
崩了吗崩 / 没崩 / 停了很久才崩
什么时候一进去就崩，还是等了一会儿

v3 / v4 / v5 会自动换图 15 次，页面顶部有一行字会数到「✓ 完成 15 次换图，本项安全」。 看到那行就说明这一项不是原因，可以直接看下一个。
