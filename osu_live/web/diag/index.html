横屏崩溃诊断

请先在竖屏打开本页，然后旋转到横屏，再逐个点开。
每个变体都是真实页面，只删掉一样东西——而且是从第一个字节就生效，不是事后注入。

  1. N0 对照组未修改。横屏应该崩，用来确认环境没变。
  2. N1 删掉横屏媒体查询把 @media (orientation: landscape) 整块从样式表里删除。
  3. N2 禁用 filter / backdrop-filter模糊是合成层的大头。
  4. N3 禁用渐变含 conic-gradient 和 linear-gradient。
  5. N4 禁用背景层的 transform + filter背景图层上的 scale + blur 组合。
  6. N5 禁用 100dvh改成 100%，排除动态视口单位。
  7. N6 禁用横屏 grid 布局退回 flex，排除网格布局。
只需要回两件事：
N0 崩了吗崩 / 没崩
N1–N6哪几个能开、哪几个崩（一句话列出来就行）

页面顶部有一条粉色横幅标着变体编号，方便确认打开的是哪一个。
